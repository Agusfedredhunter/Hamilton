# Git Innit

El comando `git innit` tiene la funcion de crear repositorios nuevos de forma local, no en el GitHub. Que significa? Significa que en el proyecto que se trabaje actualmente, se crea una subcarpeta con el nombre de `.git` y en esta carpeta se almacenaran todos los cambios realizados en el proyecto. 

A menos que uno quiera cambiar su nombre, la carpeta funcionara como el archivo donde todos los cambios registrados quedan guardados para usos futuros.
