# Comandos de Git

## git checkout // git branch

Ambos comandos son para poder trabajar con ramas en un repositorio (fundamental)

El comando `git branch` nos va a servir para crear, listar o eliminar ramas, voy con ejemplos:

`git branch Alumno_Moore`
Este comando nos crearia una rama llamada "Alumno_Moore"

`git branch`
Este comando nos va a mostrar un listado de todas las ramas creadas, y con un * nos va a mostrar en cual estamos parados actualmente

El comando `git checkout` nos va a servir para una vez creada con el comando anterior una rama, movernos para poder trabajar en esta

`git checkout Alumno_Moore`
Luego de anteriormente crear la rama, hago uso de este comando y ahora estaria trabajando en la rama adecuada
