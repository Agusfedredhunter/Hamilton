# Comandos de Git

## Git config

El comando de `git config` es uno de los comandos basicos y necesarios para el uso de git. 
Sirve justamente para configurar lo mas importante como tu usuario de git

`git config --global user.name "Andy Moore"`
`git config --global user.email "andymoore@gmail.com"`

En este caso, me apoyo en el --global para que ya me quede registrado para todos los repositorios de mi usuario, si no lo usase me serviria la configuracion unicamente para ese repositorio.
