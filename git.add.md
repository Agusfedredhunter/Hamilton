# Comandos de Git

## Git add .

El comando de `git add .` es uno de los comandos basicos para el uso del git. 
Forma parte del proceso donde un usuario procede a enviar todo el trabajo ya hecho al repositorio en github. 

Este comando en particular se encarga de hacer que todos los archivos se agrupen antes de hacer uso del comando git commit. Tambien tiene la capacidad de enviar unicamente archivos individuales si, y solo si, se agrega el nombre de dicho archivo: `git add [nombre de archivo]`
